CSUCI Capstone Project

The RoMow

Fully autonomous robotic lawn mower built with affordable off the shelf components and 3D printing for under $300

Project Overview

This was my capstone project from my undergraduate university California State University, Channel Islands. The RoMow was a culmination of four years of mechatronics engineering courses that focused on creating a fully autonomous robotic lawn mower.

The goal was to develop an affordable, efficient mower capable of navigating and mowing a small residential lawn without human intervention. RoMow combines a 3D-printed chassis with off the shelf components, showcasing that practical automation can be achieved at low cost with accessible tools and materials.

The entire system was self-funded and built for under $300, demonstrating that cutting-edge robotics and automation don't require expensive commercial solutions.

Technical Architecture

RoMow's design philosophy prioritized affordability and accessibility while maintaining robust autonomous capabilities:

Control System

  • Arduino Uno R3: Motor control and real-time decision-making
  • Raspberry Pi 3 Model B: Navigation and sensor processing
  • Dual-processor architecture for optimized task distribution

Navigation & Sensing

  • GPS-based path planning for systematic lawn coverage
  • Ultrasonic sensors for obstacle detection and avoidance
  • Mobile-friendly interface for user control and monitoring

Mechanical Design

  • 3D-printed chassis for custom fit and low cost
  • Off the shelf components for easy maintenance and replacement
  • Modular design allowing for future upgrades and modifications

Key Features

  • Fully Autonomous Operation: Navigate and mow small residential lawns without human intervention
  • GPS Path Planning: Intelligent coverage algorithms ensure complete lawn coverage
  • Obstacle Avoidance: Ultrasonic sensors detect and navigate around obstacles in real-time
  • Mobile Control Interface: User-friendly mobile interface for remote monitoring and control
  • Low-Cost Design: Total build cost under $300 using off the shelf components
  • Self-Funded: Demonstrates practical engineering on a student budget
  • Modular Architecture: Easy to maintain, upgrade, and modify for future improvements

Project Impact

The RoMow project successfully demonstrated that sophisticated autonomous systems can be built affordably using accessible technologies. By keeping the total cost under $300 and relying on off the shelf components and 3D printing, this project serves as a proof-of-concept for democratizing robotics and automation.

The system represents the culmination of four years of mechatronics engineering education, integrating mechanical design, embedded systems programming, sensor integration, and control theory into a functional autonomous platform.
